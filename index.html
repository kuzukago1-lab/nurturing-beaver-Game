もくもく川辺の遊び方ガイド

1. ゲームの目的

川辺でビーバーをお世話しながら流木を集め、立派なダムを作りましょう。ダムのレベルが上がると、ビーバーも「赤ちゃん → 子ども → おとな → 親方ビーバー」へと成長していきます。

2. 基本のお世話と進め方

  • ・エサをあげる（りんご／若枝）：100から徐々に減っていくまんぷく度を回復し、ごきげんを上げます。若枝は無料で何度でもあげられます。
  • ・なでなでする：ボタン操作のほか、川辺のビーバーを直接タップしても喜ばせられます。ごきげんが100（MAX）のときは、お世話回数を消費せずになでなでできます。水面をタップすると、そこへ泳いで移動します。
  • ・ごきげんボーナス：ごきげんが高いほど流木2本獲得率やダム建築の進捗効率、お留守番中の自動建築量がアップします。
  • ・お世話回数の制限と回復：育成アクションは1回ごとに回数を消費し、3分ごとに1回（初期上限10回・ダムLvアップごとに上限+4回＆MAX全回復）自動回復します。
  • ・流木を集める：少しまんぷく度が減りますが、ダムの材料になる流木と、買い物に使えるツヤツヤのどんぐりが手に入ります。
  • ・ダムを建築する：流木を2本使って建築を進めます。建築度が100%になるとダムがレベルアップし、お祝いにツヤツヤのどんぐり+15をもらえます。

3. レベルアップ＆ダム建築の最適ローテーション

  1. まんぷく度とごきげんの土台づくり：まんぷく度が50を切る前に若枝（無料）やりんごを与え、なでなででごきげんを高く保ちます。
  2. 流木＆ツヤツヤのどんぐりの確保：まんぷく度に余裕があるうちに流木を集めるを繰り返し、流木とツヤツヤのどんぐりを貯めます。
  3. ダム建築ラッシュ：流木が貯まったらダムを建築するで建築度100%を目指し、レベルアップ報酬（ツヤツヤのどんぐり+15）を獲得します。
  4. 報酬の循環＆おでかけ活用：得たツヤツヤのどんぐりでりんごを補充し、よその川辺へおでかけして流木をおすそわけすると、さらに効率よくレベルアップできます。

4. 時間経過とお留守番

ゲームを閉じている間も時間が進み、まんぷく度が少しずつ減っていきます。まんぷく度が50以上なら、お留守番中も自分で少しずつダムの建築を進めてくれます。

5. よその川辺へおでかけ

下の「よその川辺」タブから他の飼い主の川辺へ遊びに行けます。よそのビーバーをなでたり流木をおすそわけしたりすると、お礼にツヤツヤのどんぐりをもらえます。
